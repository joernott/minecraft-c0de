Returns the arc tangent of a number.

The result is an angle in radians.

- `value` INTEGER|FLOAT: the tangent
- result `result` FLOAT: the angle in radians

```c0de
CALL c0de/math/ATN
  PARAMETER value slope ;
  RESULT result angle
```
