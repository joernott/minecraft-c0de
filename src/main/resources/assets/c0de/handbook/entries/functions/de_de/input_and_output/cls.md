Löscht die Bildschirme.

Der Cursor der Bildschirme springt auf Zeile 0, Spalte 0. CLS wirkt auf alle Bildschirme, die an das Programm und die Funktion gebunden sind.

- keine Parameter und keine Ergebnisse
