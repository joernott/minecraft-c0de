Typblöcke sind rote Stufen. Jeder wird aus einer Typbasis und einem Gegenstand hergestellt, in beliebiger Form:

- BOOLEAN: Redstone-Fackel
- INTEGER: Sand
- FLOAT: roter Sand
- CHAR: Eichenholzbretter
- STRING: Faden
- ARRAY: Fass
- HASH: Truhe
- STRUCT: Gerüst
- TIME: Uhr
- ERROR: Lagerfeuer

[VARIABLE](^language/variables_and_constants) ist eine Typbasis und ein Knochenblock. CONSTANT ist eine Typbasis und drei Knochen.
