This library lets programs touch the world around the trigger block:

- TICKS: the game time of the world, not the time of day
- BEEP, SOUND: play notes like a note block
- SAY: write a message to the chat
- GET\_BLOCK: read a block, its redstone power and its data
- GET\_INVENTORY: read the items in a chest or other container

- GET\_LEVER, SET\_LEVER: read or flip levers
- GET\_BUTTON, PRESS\_BUTTON: read or press buttons
- GET\_PRESSURE\_PLATE: read pressure plates
- GET\_OPEN, SET\_OPEN: doors, trapdoors and fence gates
- FIND\_ENTITIES: find mobs and items nearby
