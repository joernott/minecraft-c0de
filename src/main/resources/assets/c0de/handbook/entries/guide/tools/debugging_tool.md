The debugging tool looks like a fly swatter. Right-click any c0de block with it to see all its properties. For a red [line number](^getting_started/line_numbers), it tells you what is wrong.

Hit a [debug trigger block](^running_programs/three_trigger_blocks) with it to start a process with a red **[debug cursor](^running_programs/the_cursor)**. The debug cursor starts paused.

- Left-click the paused cursor: it moves one line.
- Shift-left-click the cursor: it runs on its own, or pauses again.
- Right-click any cursor: see its properties and its stack.
- Shift-right-click a [PID block](^running_programs/pid_blocks): abort the process.

Recipe: a red wool block bottom left, a stick in the middle and a leather top right.
