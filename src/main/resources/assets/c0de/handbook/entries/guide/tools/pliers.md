The pliers change the [indentation](^language/lines_and_indentation) of your code. Left-click a line to move it one block to the left. Right-click it to move it one block to the right. If the line is part of a marked area, the whole area moves.

Nothing moves if a block would leave the code area. The message tells you which line is in the way. The pliers don't check whether the new indentation is right, but the [line numbers](^getting_started/line_numbers) show it.

Recipe: shears and a stick, in any shape.
