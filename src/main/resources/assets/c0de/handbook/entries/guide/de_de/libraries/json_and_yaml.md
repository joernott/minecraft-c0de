[c0de/strings](^libraries/c0de_strings) kann außerdem jeden Wert mit TO\_JSON und TO\_YAML in JSON- oder YAML-Text verwandeln. FROM\_JSON und FROM\_YAML lesen solchen Text zurück in eine Variable.

TAG-Blöcke am Ende einer VARIABLE-Zeile oder eines Strukturelements legen die Schlüsselnamen fest, die in JSON oder YAML verwendet werden.
