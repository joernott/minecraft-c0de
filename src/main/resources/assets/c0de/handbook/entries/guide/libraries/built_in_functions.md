These work without [INCLUDE](^libraries/including_libraries):

- LEN: the length of a text, array or hash
- HAS\_KEY: true if a hash has a key
- REMOVE: an array or hash without one element
- INSERT: an array with a new element at a position
- CLEAR: an empty array or hash
- SWAP: swaps two values
- [RAISE](^language/your_own_errors): raises your own error, code 1000 or higher
