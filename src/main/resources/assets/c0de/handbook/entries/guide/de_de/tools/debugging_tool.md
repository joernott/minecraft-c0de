Das Debugging-Werkzeug sieht aus wie eine Fliegenklatsche. Rechtsklicke damit auf einen beliebigen c0de-Block, um alle seine Eigenschaften zu sehen. Bei einer roten [Zeilennummer](^getting_started/line_numbers) sagt es dir, was falsch ist.

Schlage damit auf einen [Debug-Auslöserblock](^running_programs/three_trigger_blocks), um einen Prozess mit einem roten **[Debug-Cursor](^running_programs/the_cursor)** zu starten. Der Debug-Cursor startet pausiert.

- Linksklick auf den pausierten Cursor: Er geht eine Zeile weiter.
- Shift-Linksklick auf den Cursor: Er läuft von selbst oder pausiert wieder.
- Rechtsklick auf einen beliebigen Cursor: Zeigt seine Eigenschaften und seinen Stack.
- Shift-Rechtsklick auf einen [PID-Block](^running_programs/pid_blocks): Bricht den Prozess ab.

Rezept: ein Block roter Wolle unten links, ein Stock in der Mitte und ein Leder oben rechts.
