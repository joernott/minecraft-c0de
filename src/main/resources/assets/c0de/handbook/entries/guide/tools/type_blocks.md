Type blocks are red slabs. Each is crafted from a type base and an item, in any shape:

- BOOLEAN: redstone torch
- INTEGER: sand
- FLOAT: red sand
- CHAR: oak plank
- STRING: string
- ARRAY: barrel
- HASH: chest
- STRUCT: scaffolding
- TIME: clock
- ERROR: campfire

VARIABLE is a type base and a bone block. CONSTANT is a type base and three bones.
